# SQL-QUERIES
Some SQL Practice Queries

## Files
- `First SQL Assignment.sql` – basic `SELECT` / `WHERE` filtering
- `Inner Join Assignment.sql` – `INNER JOIN` practice across the healthcare tables
- `Studentgrades.sql` – queries on the student grades dataset
- `Data Science Queries.sql` – data science techniques in T-SQL on the healthcare tables: data profiling, data quality checks, descriptive statistics, outlier detection (z-score and IQR), feature engineering, window functions, time series, segmentation and cohorts, correlation and regression, and train/test splitting
